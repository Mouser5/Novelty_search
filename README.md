# ЛР3: поиск новизны (Novelty Search) + NEAT — робот в лабиринте

## Установка

```bash
python -m pip install -r requirements.txt
python tests/test_basic.py
```

Нужен Python 3.9+. Зависимости: neat-python, numpy, matplotlib. После проверки все строки должны начинаться с `OK`.

## Структура

| Файл | Что внутри |
|---|---|
| `nsmaze/maze.py` | лабиринт: загрузка и сохранение карт, генератор лабиринтов разной сложности, оценка сложности |
| `nsmaze/simulator.py` | симулятор робота: датчики, движение, столкновения; описание поведения |
| `nsmaze/batchnet.py` | одновременное вычисление всех сетей популяции |
| `nsmaze/novelty.py` | мера новизны ρ(x) и архив с порогом ρmin |
| `nsmaze/evolution.py` | запуск эволюции для всех методов, сбор статистики, параллельные серии запусков |
| `nsmaze/plots.py` | тепловые карты, траектории, сравнение методов, характеристические карты |
| `run_experiment.py` | серия запусков: методы × лабиринты |
| `sweep.py` | характеристические карты: перебор одного или двух параметров |
| `make_mazes.py` | генерация набора лабиринтов и их галереи |

| `tests/test_basic.py` | проверки датчиков, физики, меры новизны, генератора |

## Модель

**Робот:** радиус 8; 6 дальномеров (−90°, −45°, 0°, 45°, 90°, 180°, дальность 100); 4 радара-сектора по 90°,
показывающих направление на выход; 2 выхода сети — приращения угловой и линейной скорости (ограничены ±3).
Оценка — 400 шагов; выход найден, если робот ближе 5 к точке выхода.

**Поведение:** точка остановки `(x, y)` (`--behavior endpoint`) или позиции через каждые 50 шагов (`--behavior trajectory`).

**Новизна:** ρ(x) = (1/k) Σ dist(x, μᵢ) по k ближайшим соседям среди популяции и архива.
Особь попадает в архив, если ρ(x) > ρmin. При динамическом пороге ρmin растёт на 20 %, если за поколение
добавлено больше 4 особей, и падает на 5 %, если 10 поколений подряд никто не добавлен.

**Методы** (`--method`):

| Метод | Описание |
|---|---|
| `novelty` | NEAT + поиск новизны |
| `fitness` | NEAT с целевой функцией f = D − d (D — диагональ лабиринта, d — расстояние до выхода в точке остановки) |
| `random` | NEAT со случайной приспособленностью |
| `mcns` | поиск новизны с минимальным критерием: особи, не выполнившие его, получают 0 и не попадают в архив |
| `mapelites` | MAP-Elites: сетка по точке остановки, в клетке — лучшая по f особь |

Критерий MCNS: `--mc-kind progress` — продвинуться к выходу не меньше чем на `--mc-value` (1 %) начального
расстояния; `--mc-kind moved` — отойти от старта не меньше чем на `mc-value` × диагональ лабиринта.

## Параметры

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--pop-size` | 250 | размер популяции |
| `--max-evals` | 100000 | лимит оценок на запуск |
| `--k` | 15 | число ближайших соседей в мере новизны |
| `--threshold` | 6.0 | начальный порог архива ρmin |
| `--dynamic-threshold` | true | подстраивать ли порог |
| `--behavior` | endpoint | описание поведения: `endpoint` или `trajectory` |
| `--sample-every` | 50 | шаг выборки траектории |
| `--node-add-prob`, `--conn-add-prob` | 0.1, 0.5 | вероятности добавления нейрона и связи |
| `--weight-mutate-rate`, `--weight-mutate-power` | 0.8, 0.5 | мутация весов |
| `--compatibility-threshold` | 3.0 | порог совместимости видов NEAT |
| `--steps` | 400 | шагов симуляции на одну оценку |
| `--me-bins` | 20 | размер сетки MAP-Elites |
| `--mc-kind`, `--mc-value` | progress, 0.01 | минимальный критерий MCNS |
| `--runs`, `--seed0` | 5, 0 | число запусков и первое зерно |
| `--workers` | число ядер | число параллельных процессов |
| `--progress-every` | 25 | печатать ход запуска каждые N поколений (0 — не печатать) |

## Показатели качества

Столбцы `summary.csv` и `sweep.csv`:

* `solved` — решена ли задача; по серии — доля решённых запусков;
* `evals` — число оценок до решения (если не решено — сколько потрачено);
* `coverage` — покрытие лабиринта: доля проходимых клеток 10×10, где останавливался хотя бы один робот;
* `best_dist` — лучшее расстояние до выхода (для нерешённых запусков);
* `archive_size`, `final_threshold` — размер архива и итоговый порог;
* `solver_nodes`, `solver_conns` — размер сети решившего (или лучшего) робота;
* `time_s` — время запуска.

В каждом `.pkl` также сохранены история по поколениям и точки остановки всех роботов.

## План экспериментов

**Подготовка:**
```bash
python tests/test_basic.py
python make_mazes.py
```

**Сравнение с аналогами** на сложном лабиринте:
```bash
python run_experiment.py --maze hard --method novelty fitness random mapelites mcns --runs 8 --out results/hard
```

**Характеристические карты** (поиск новизны, лабиринт `hard`):
```bash
python sweep.py --maze hard --param k --values 1 3 7 15 30 --runs 8
python sweep.py --maze hard --param threshold --values 1 3 6 12 24 --dynamic-threshold false --runs 8
python sweep.py --maze hard --param pop_size --values 50 100 250 500 --runs 8
python sweep.py --maze hard --param behavior --values endpoint trajectory --threshold 20 --runs 8
```

**Влияние сложности лабиринта:**
```bash
python run_experiment.py --maze open grid2x2 grid3x3 grid4x4 grid5x5 grid6x6 --method novelty --runs 8 --out results/complexity
```

**Перерисовка рисунков** по сохранённым результатам:
```bash
python make_figures.py results/hard
```
